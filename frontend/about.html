About LoadBlast

A distributed load-testing platform built from scratch. By angelawu236 on GitHub at angelawu236/load-tester.

What it does

LoadBlast fans out HTTP load across a swarm of async virtual users, streams live metrics to a dashboard in real time, and produces a summary when the test completes. It supports two modes: hammering a single URL, or running a multi-step API flow where each step can extract and inject values from the previous response.

How it works

Worker

Async Python coroutines simulate concurrent virtual users using a single event loop. Each second, a metrics snapshot is published — RPS, latency percentiles, error counts, status code breakdown.

Control API

FastAPI backend orchestrates workers via Kubernetes Jobs. Metrics flow through Redis pub/sub and are fanned out to all connected WebSocket clients in real time.
